5. BACKEND APIS CONNECTED
--------------------------------------------------------------------------------
Farm Management:
- POST   /api/farms        -> Create farm (authenticated farmer derived from JWT)
- GET    /api/farms        -> List farmer's owned farms
- GET    /api/farms/{id}   -> Get farm details with ownership check
- PUT    /api/farms/{id}   -> Update farm details
- DELETE /api/farms/{id}   -> Delete farm and cascade delete associated animals

Animal Management:
- POST   /api/animals              -> Register animal under owned farm (verifies tag uniqueness in farm)
- GET    /api/animals              -> List all animals owned across user's farms
- GET    /api/animals?farmId={id}  -> List animals belonging to specific owned farm
- GET    /api/animals/{id}         -> Get animal details with ownership check
- PUT    /api/animals/{id}         -> Update animal profile and production records
- DELETE /api/animals/{id}         -> Delete animal profile
