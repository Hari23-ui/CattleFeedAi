1. MILESTONE NAME
-----------------
M7.2 — Image-Based Visual Analysis (Visual Screening & Physical Quality Pipeline)


2. OBJECTIVE
------------
Implement a robust, production-ready, image-based visual analysis pipeline for 
Feed and Silage samples across the Python FastAPI AI microservice, Spring Boot 
backend, and React Native / Expo frontend.

Key functional capabilities:
- Physical image validation and safety guards (decompression bomb guard, format checks).
- Deterministic image preprocessing (RGBA-to-RGB alpha compositing, aspect-ratio-preserving downscaling).
- Quantitative physical image quality assessment (luminance, contrast std-dev, resolution, usability grade).
- Deterministic surface screening heuristics for physical indicators:
  * Mould-like surface appearance
  * Spoilage-like discolouration
  * Foreign material / debris presence
  * Image quality limitations
- Seamless Spring Boot client integration forwarding stored sample attachments and direct uploads.
- Interactive React Native UI with "AI Screen" action, modal screening presentation, visual indicators, confidence scores, and quality grading.

CRITICAL SCIENTIFIC SAFETY BOUNDARIES (STRICTLY ENFORCED):
- VISUAL SURFACE SCREENING ONLY.
- ZERO chemical attribute predictions (NO crude protein %, moisture %, fiber %, aflatoxin ppb, pH, etc.).
- ZERO animal disease diagnosis (NO clinical assertions, no pathology claims).
- Prominent non-diagnostic disclaimer delivered on every single analysis response:
  "NOTICE: VISUAL SCREENING ONLY. This analysis is an automated physical surface inspection based solely on camera image characteristics. It does NOT measure chemical attributes (such as crude protein, moisture, dry matter, or aflatoxins) and does NOT diagnose animal diseases. Laboratory testing is required for definitive nutritional and safety verification."

   - aflatoxin, mycotoxin
   - ph, tdn, nel
2. NO animal disease diagnoses exist:
   - disease, diagnosis, mastitis, acidosis, etc.
