1. OBJECTIVE
------------
Design, implement, and integrate a modular Computer Vision and Machine Learning 
(ML/CV) model inference architecture for CattleFeedAI, connecting the Python 
FastAPI AI microservice, Spring Boot backend, and React Native frontend.

Key deliverables:
- Formal ML/CV model interface and abstraction layer (VisualModel).
- Configurable model loader supporting safe startup, missing-weight handling, 
  and runtime enablement toggles.
- Concrete visual surface classifier (VisualClassifierModel) evaluating spatial 
  quadrant features for mould, spoilage, and foreign material.
- Dedicated inference orchestration service (MLInferenceService) with seamless 
  fallback to the verified M7.2 deterministic screening pipeline.
- Model versioning, availability discovery, and analysis source transparency 
  (ML_VISUAL_SCREENING vs DETERMINISTIC_VISUAL_SCREENING).
- End-to-end multi-tier integration through Spring Boot client DTOs and React 
  Native UI indicators.
- Strict enforcement of non-diagnostic scientific boundaries.

ai-service/app/services/:

4. MODEL ABSTRACTION
--------------------
Defined in app/models/base.py:
- VisualModel (Abstract Base Class):
  * load() -> bool
  * is_available() -> bool
  * predict(image: PIL.Image.Image) -> MLPredictionResult
  * model_version() -> Optional[str]
  * model_name() -> str
- VisualPrediction: dataclass capturing label, confidence (0.0-1.0), severity 
  (LOW/MEDIUM/HIGH), and evidence explanation.
- MLPredictionResult: dataclass capturing model_available, model_version, 
  model_name, and predictions list.


5. MODEL LOADING
----------------
Defined in app/models/model_loader.py:
- load_visual_model() factory inspects configuration (MODEL_ENABLED, MODEL_PATH).
- If MODEL_ENABLED is False or weights are missing, it initializes a 
  DisabledVisualModel null-object without throwing exceptions or crashing the server.
- Handles corrupt or missing files safely and logs diagnostic warnings.


6. MODEL CONFIGURATION
----------------------
Configured via Pydantic BaseSettings in app/config.py:
- SERVICE_VERSION: "0.3.0"
- MODEL_ENABLED: bool = False (safe default; toggleable via environment)
- MODEL_PATH: Optional[str] = None
- MODEL_VERSION: str = "visual-classifier-1.0"
- MODEL_NAME: str = "CattleFeed-VisualNet-Baseline"
- MODEL_CONFIDENCE_THRESHOLD: float = 0.50


7. INFERENCE PIPELINE
---------------------
Full request processing flow:
1. Image Bytes Input (JPEG, PNG, WebP)
2. Validation & Decompression Bomb Guard (MAX_IMAGE_PIXELS = 25_000_000)
3. Preprocessing (RGBA/LA/P to RGB via background compositing, aspect downscale)
4. Physical Image Quality Assessment (Resolution, Mean Luminance, Contrast Std-dev)
5. ML/CV Model Execution:
   - If model.is_available():
       * Model runs prediction on preprocessed image.
       * Predictions with confidence >= MODEL_CONFIDENCE_THRESHOLD are extracted.
       * analysis_source is set to "ML_VISUAL_SCREENING".
       * model_available = True, model_version = active version.
   - If model is NOT available or disabled:
       * Pipeline delegates directly to the deterministic M7.2 screening baseline.
       * analysis_source is set to "DETERMINISTIC_VISUAL_SCREENING".
       * model_available = False, model_version = None.
6. Usability Guard:
   - If image quality status is UNUSABLE, both ML and deterministic paths return 
     status = INSUFFICIENT_DATA and suppress false indicator detections.
7. Serialization & Delivery:
   - Response DTO dispatched to Spring Boot (:8080) and presented on React Native UI.


8. FALLBACK BEHAVIOR
--------------------
When MODEL_ENABLED=False or no trained model file is configured, the system 
executes the verified M7.2 deterministic surface screening heuristics.
There is ZERO downtime, ZERO degradation of existing screening capabilities, 
and ZERO disruption to upstream Spring Boot or React Native clients.

12. SCIENTIFIC SAFETY & NON-DIAGNOSTIC BOUNDARY
-----------------------------------------------
STRICTLY ENFORCED:
1. Zero chemical parameter predictions:
   - No crude protein %, moisture %, dry matter %, fiber %, ash %, energy value,
     aflatoxin ppb, mycotoxin concentration, pH, minerals, urea, or any lab value.
2. Zero animal disease diagnosis:
   - No mastitis, acidosis, ketosis, disease, pathology, or veterinary diagnosis.
3. Mandatory disclaimer on every response and UI view:
   "NOTICE: VISUAL SCREENING ONLY. This analysis is an automated physical surface 
   inspection based solely on camera image characteristics. It does NOT measure 
   chemical attributes (such as crude protein, moisture, dry matter, or aflatoxins) 
   and does NOT diagnose animal diseases. Laboratory testing is required for 
   definitive nutritional and safety verification."

18. LIMITATIONS
---------------
- Current ML classifier operates on spatial color and texture feature vectors; 
  deep learning convolutional weights are intentionally decoupled until a validated 
  domain-specific dataset is acquired.
- The pipeline assesses physical visual surface conditions only; internal fungal 
  pockets or chemical degradation cannot be observed by visual cameras.


19. FUTURE IMPROVEMENTS & EXCLUSIONS
