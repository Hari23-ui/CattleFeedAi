1. OBJECTIVE
================================================================================
Implement a robust, complete expert consultation workflow connecting dairy farmers
with qualified animal health and veterinary nutrition experts (Veterinarians,
Veterinary Nutritionists, Animal Nutrition Experts).

The workflow enables farmers to submit targeted advisory inquiries linking their
specific cattle herd profiles, feed samples, silage quality assessments, lab test
results, and AI-assisted visual screenings. Qualified experts can review this complete
context, claim/accept consultations, move them through active clinical review,
provide authoritative professional recommendations and notes, and finalize completed
consultations.

Strict Non-Diagnostic Boundary:
This workflow is a professional advisory support system, NOT an automated veterinary
diagnosis system. Automated disease diagnosis, guaranteed clinical treatments, and
fabricated laboratory measurements are strictly prohibited.

5. CONSULTATION LIFECYCLE
================================================================================
Lifecycle transitions are strictly validated and controlled by backend logic:

                 REQUESTED
                /         \
   (Expert accepts)      (Farmer cancels)
              /             \
          ACCEPTED       CANCELLED
             |
   (Expert reviews)
             |
          IN_REVIEW
             |
   (Expert responds)
             |
          RESPONDED
             |
   (Expert completes)
             |
          COMPLETED

State Rules:
1. When created by farmer -> REQUESTED.
2. Only open (unassigned) REQUESTED consultations can be claimed/accepted by an expert -> ACCEPTED.
3. Once accepted, moving into review -> IN_REVIEW.
4. Responding with recommendation and notes -> RESPONDED (records responseDate).
5. Only RESPONDED consultations can be finalized -> COMPLETED (records completedAt).
6. Farmers can cancel ONLY while in REQUESTED or ACCEPTED status; once review/response begins,
   cancellation is rejected with 400 Bad Request.
7. Status cannot be modified arbitrarily or regressed from terminal states (COMPLETED, CANCELLED).

================================================================================
6. FARMER WORKFLOW
================================================================================
1. Farmer logs into CattleFeedAI and taps "+ Request Consultation" on Dashboard.
2. Farmer enters Subject, detailed Question/Concern, and optional Additional Context.
3. Farmer optionally links an owned Animal, Feed Sample, or Silage Sample.
4. System validates inputs and creates consultation with status REQUESTED.
5. Farmer can track consultation status on "My Consultations" screen.
6. If needed, farmer can cancel the consultation before review commences.
7. When the expert responds, farmer opens Consultation Details to view:
   - Expert name, qualifications, and specialization
   - Authoritative Professional Recommendation
   - Additional Expert Advisory Notes
   - Response date and completion timestamp

================================================================================
7. EXPERT WORKFLOW
================================================================================
1. Qualified expert (Veterinarian / Nutritionist) registers/logs in with EXPERT role.
2. Expert views "Consultation Requests" on Dashboard to view assigned and open inquiries.
3. Expert taps an open consultation to inspect the farmer's concern.
4. Expert clicks "Accept Consultation" to assign themselves and move status to ACCEPTED.
5. Expert clicks "Start Review" to transition to IN_REVIEW.
6. Expert inspects all linked objective data:
   - Animal Tag, Breed, Age, Lactation Stage, Daily Milk Yield, Weight, Pregnancy Status
   - Feed / Silage Sample Code, Type, Source, Sample Date
   - Laboratory Test Results (Moisture, Crude Protein, Fiber, pH, Overall Quality)
   - Attached sample images and AI visual screening results
   - Active herd health risks and advisories
7. Expert clicks "Provide Recommendation", enters clinical advisory recommendation and notes.
8. Submitting moves status to RESPONDED.
9. Expert marks consultation as COMPLETED once advisory engagement concludes.

9. SECURITY & AUTHORIZATION
================================================================================
- Authentication:
  Stateless JWT bearer tokens issued upon login/registration with role claims.
  Unauthenticated requests are strictly rejected with HTTP 401 Unauthorized.
- Ownership Enforcement:
  * Farmers cannot view, respond to, or cancel another farmer's consultation (HTTP 403 Forbidden).
  * Farmers cannot accept consultations or mark them completed (HTTP 403 Forbidden).
  * Experts cannot access private consultations assigned to another expert (HTTP 403 Forbidden).
  * Farmers can only link animals, feed samples, or silage samples from farms they own.
- Resource Verification:
  Missing consultation IDs strictly return HTTP 404 Not Found.
- State Validation:
  Invalid status transitions strictly return HTTP 400 Bad Request.
