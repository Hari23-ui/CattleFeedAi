6. SCREENS IMPLEMENTED
----------------------
Feed Screens (src/screens/feed/):
- FeedListScreen: real backend list, pull-to-refresh, farm filter, empty/loading/error states, + Add Feed action.
- FeedDetailsScreen: complete sample details, linked farm/animal, associated test results history, + Record Test Result, Edit & Delete actions with confirmation alert.
- AddFeedScreen: farm selector, optional animal selector, sample code, feed type, sample date, storage/source, notes, backend-aligned validation.
- EditFeedScreen: pre-populated feed sample form, submit to PUT /api/feed-samples/{id}.

Silage Screens (src/screens/silage/):
- SilageListScreen: real backend list, pull-to-refresh, farm filter, loading/error states, + Add Silage button.
- SilageDetailsScreen: complete sample details, bunker/pit indicators, associated test results, + Record Test Result, Edit & Delete actions with confirmation alert.
- AddSilageScreen: farm selector, optional animal selector, silage type selector, sample date, storage bunker/pit, fermentation observations.
- EditSilageScreen: pre-populated silage sample form, submit to PUT /api/silage-samples/{id}.

Test Results Screens (src/screens/testResults/):
- AddTestResultScreen: parent sample selection (feed vs silage or pre-locked via route params), test date, analysis source selector, quantitative measurements (moisture, crude protein, fiber, energy value, aflatoxin, mycotoxin, pH, confidence score), sensory flags (mould detected, spoilage detected), mineral status, adulteration observations.
- TestResultDetailsScreen: complete breakdown of chemical & sensory measurements; strictly displays "Not Available" for null fields without converting to 0 or safe/good; displays overallQuality badge if returned by backend; link back to parent sample.
- TestResultListScreen: historical list of tests for a selected or locked feed/silage sample, pull-to-refresh, empty/error states, + Record Test action.

8. ERROR HANDLING
-----------------
- 401 Unauthorized: Handled automatically by apiClient interceptor redirecting to login.
- 403 Forbidden: Friendly "Access denied. You do not have permission to access this resource."
- 404 Not Found: Resource not found message with Retry or Back actions.
- 409 Conflict: Preserves backend duplicate sample code conflict message.
- 400 Bad Request / Validation: Surfaces field-level errors to farmer.
- 500 Internal Error: Sanitized "Something went wrong on our end" without leaking stack traces or SQL.
- Network & Timeout Errors: User-friendly offline / connectivity retry banner.
